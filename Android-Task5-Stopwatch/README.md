## Stopwatch App (Task 5)

A beautiful, functional stopwatch Android application developed as part of the Oasis Infobyte Student Internship Program (OIBSIP).

### Features
- Accurate time tracking using Android `Handler` and `SystemClock`.
- Start, Pause, and Reset functionality.
- Dynamic color-changing buttons based on state.
- **Lap tracking**: Allows users to record specific lap times to a scrollable list.
- Lifecycle aware (pauses UI updates when in background to save battery).

### Tech Stack
- **Language**: Java
- **IDE**: Android Studio
- **UI Components**: ConstraintLayout, MaterialButtons, ScrollView, LinearLayout.

### Installation
1. Clone the repository: `git clone https://github.com/fahad11560/OIBSIP.git`
2. Navigate to this folder: `cd OIBSIP/Android-Task5-Stopwatch`
3. Open the project in Android Studio.
4. Build the project using Gradle.
5. Run the app on an emulator or a physical device.
