# Task 1: Unit Converter App

## 📖 Description
A colorful and highly functional Unit Converter Android application developed as part of the Oasis Infobyte Student Internship Program (OIBSIP). The app supports dynamic real-time conversion and adaptive Light/Dark mode themes.

## 🎯 Features
- ✅ Converts Length (Meter, Kilometer, Mile, etc.), Weight (Gram, Kilogram, Pound, etc.), and Temperature.
- ✅ Real-time auto-conversion as you type.
- ✅ Dedicated "Convert" button for manual calculation.
- ✅ "Swap" button (🔄) to easily invert Source and Target units.
- ✅ Beautiful UI with gradient buttons and rounded cards.
- ✅ Fully supports Android Light Mode and Dark Mode.
- ✅ Input validation to prevent crashes from empty or invalid data.

## 🛠️ Tech Stack
- **Language:** Java
- **IDE:** Android Studio
- **Min SDK:** API 24
- **Layout:** ConstraintLayout, Spinners
- **Features:** TextWatcher (Auto-calculate), custom XML drawables

## 🚀 How to Run
1. Clone: `git clone https://github.com/fahad11560/OIBSIP.git`
2. Open `Android-Task1-UnitConverter` folder in Android Studio
3. Build and run on emulator or physical device
